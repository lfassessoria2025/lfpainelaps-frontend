# lfpainelaps-frontend

Frontend da Plataforma de Dados de Saúde (React + Vite + TypeScript).

`main` é a branch de produção: recebe apenas promoções deliberadas de um estado já
aprovado (QA + CR) de `developer`. Não é usada para desenvolvimento cotidiano.

O trabalho ativo acontece em `developer`. Ver `PLANO-FRONTEND.md` (em `developer`) para
o plano de fases e o contrato de API consumido do backend.
